# JVoice — план интерфейса и карта элементов

Договорённости для будущего обновления интерфейса. Пока это план: расположение
и новые подписи Edge / Clarity ещё не реализованы. Параметры и их назначение
не меняются автоматически при переименовании.

Основные элементы сделать крупнее; остальные разделить на смысловые группы,
ориентировочно по четыре ручки. Это рабочая раскладка для дальнейшего обсуждения.

## Main — главные

Порядок: **Shift · Detune · Speech Rate · Voices**. Рядом галки Unison и Mono.

- **Shift** — сдвиг формант, −12…+12 полутонов.
- **Detune** — расстройка голосов до ±40 центов.
- **Speech Rate** — длительность согласных, 50–600%; 100% — исходная.
- **Voices** — 1–8 голосов; при Unison — число слоёв.

## Voice — характер

- **Edge** (сейчас Buzz) — характер тонального источника: яркость, форма,
  а также встроенная нестабильность и вибрато.
- **Breath** — дыхание и шёпот.
- **Q** — добротность формантных резонаторов.
- **Smear** — морфинг гласных; центр сохраняет исходный звук.

## Articulation — произношение

- **Clarity** (сейчас Artic) — чёткость согласных и артикуляции в целом.
- **Slew** — скорость перетекания формант, 1–1000%; 100% по центру.
- **Grain** — характер шумных согласных: исходный шум на нуле, добавление
  dust-импульсов, которые к максимуму становятся реже.
- **Release** — время отпускания ноты.

## Motion — движение высоты

- **Glide** — скольжение высоты, 0–10 секунд.
- **Mod Depth** — максимальная глубина вибрато от Mod Wheel.
- **Mod Rate** — скорость вибрато.
- **Decouple** (сейчас Mod Decouple) — расхождение фаз вибрато голосов; на нуле синхронно.
- **Glide Direction** — список Both / Up / Down рядом с Glide; Up и Down
  сравнивают новую ноту с последней сыгранной на том же MIDI-канале.

## Voices / Output — голоса и выход

- **Image** — стереоразведение голосов. Перенести сюда из главной группы.
- **Swarm** — разброс длительности Glide между слоями Unison; доступен при Unison.
- **Ext. Gain** (сейчас Ext. Input Gain) — уровень внешней несущей; рядом включение Ext. Input.
- **Volume** (сейчас Master Volume) — общая выходная громкость.

Эту четвёрку можно визуально разделить на две пары: Image / Swarm и
Ext. Gain / Volume. Группы не обязаны состоять ровно из четырёх
элементов, если это мешает удобству.

## Другие элементы

- **Unison** — несколько голосов на ноту.
- **Mono** — одна текущая MIDI-нота.
- **Velo** — включение MIDI velocity; по умолчанию выключено, ноты получают 100.
- **Ext. Input** — внешняя стереонесущая через sidechain.
- **Newspeak** — продвижение по одной фонеме на ноту.
- **Pitch Bend Range** — диапазон ±1…±12 полутонов.
- **Language**, выбор строки, Previous / Next / Restart и поле текста.

Ручки и переключатели должны оставаться доступными для автоматизации. При
переименовании сохранить идентификаторы параметров и поведение существующих
проектов. Новая расстановка и подписи будут отдельной работой.
