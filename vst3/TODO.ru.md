# JVoice — задачи

- [x] Переименовать **Phon. Glide** в **Slur**. Расширить минимум с 25% до 1%, максимум оставить 1000%. Сохранить привычное значение 100% по умолчанию и по центру ручки. Проверить поведение на очень коротких переходах.
- [x] Добавить отдельный автоматизируемый **Glide** для плавного изменения высоты ноты: от 0 до 10 секунд, по умолчанию 0. Поддержать Mono, Unison и полифонию, включая переходы между голосами при смене аккордов. При реализации определить предсказуемое соответствие старых и новых нот и проверить переходы без щелчков. Внешнюю несущую Ext. Input без отдельного питч-шифтинга не транспонировать.
- [x] Исправить выпадающий список **Pitch Bend Range**: при выборе мышью список прыгает к предыдущему значению. Проверить обновление интерфейса, пока список раскрыт, и сохранить работу автоматизации и колеса мыши.
