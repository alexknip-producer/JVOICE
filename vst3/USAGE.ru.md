# JVoice 0.3.8 — construction demo

**Vtrx** — экспериментальный режим с приблизительными формантами из модели Votrax SC-01A в MAME. Частоты рассчитаны для тактирования 720 кГц; это приближение, а не полная эмуляция чипа. Для русского используются дополнительные поправки JVoice; мягкие согласные и раскатистая Р сохранены. Переключатель сохраняется в проекте. Таблица: `src/VtrxFormants.csv`. Значения вычислены по модели фильтров [MAME Votrax SC-01](https://github.com/mamedev/mame/blob/master/src/devices/sound/votrax.cpp) и восстановленным параметрам [SC-01A](https://github.com/shufps/votrax-sc01a-vhdl).

VST3-инструмент для Windows x64. Интерфейс полностью на английском.

Новый экземпляр открывается с German (DE) и текстом
`pulsare quasare die sonne der mond die sterne`. Сохранённые проекты
восстанавливают свои текст и язык.

## Установка

Закройте DAW, замените прежнюю папку плагина целиком на `JVoice.vst3` в
`C:\Program Files\Common Files\VST3\` и обновите список плагинов.
Уберите прежний `JiantVoice.vst3`: идентификатор инструмента сохранён для
совместимости проектов, поэтому две версии одновременно ставить не нужно.
В списке инструментов новое имя — **JVoice**.

## Текст и выбор строк

Одно многострочное поле: Enter начинает новую строку. До **13 строк по 128
символов Unicode**. Пустые строки тоже имеют номер. Кириллица сохраняется в
исходном виде; таблица транслитерации находится в `src/TransliterationTable.h`.

Выберите строку списком, кнопками Previous / Next либо поставьте
курсор в тексте и нажмите Select cursor line. MIDI-ноты **0–12**
тоже выбирают строки 1–13 и сами не звучат. Подпись **C−2…C−1 включительно**
соответствует этой нумерации; в DAW с другим названием октав ориентируйтесь
на номера MIDI. Звучащие ноты начинаются с номера **13**.

Новая нота продвигает текст на слог. Ноты аккорда с одной временной отметкой
используют один слог. Удержание продолжает гласную; Note Off завершает ноту.
Переключение строки и кнопка Restart возвращают чтение к началу.
При переходе транспорта DAW из Stop в **Play**, а также при скачке позиции
проекта (перемещение курсора или возврат цикла) выбранная строка начинается
заново. Уже звучащие ноты продолжают свой текст.

## Ручки и автоматизация

| Ручка | Действие |
| --- | --- |
| Speech Rate | CONS из прошивки: длительность согласных **50–600%**. Больше — длиннее и медленнее; 100% — исходная длительность. |
| Phoneme Glide | Время перетекания формант **25–1000%** относительно родного движка. **100% по центру** — нынешние времена; независимо от Speech Rate. |
| Shift | Формантный сдвиг **−12…+12 полутонов**, без транспонирования сыгранной ноты. |
| Smear | Морфинг текущих гласных по кругу **A–I–E–A–O–U**, в обе стороны. **0% по центру** сохраняет исходную гласную. Высота ноты не меняется. |
| Q | Добротность формантных резонаторов. |
| Breath | Примесь дыхания / шёпот. |
| Buzz | Характер и яркость голосового источника. |
| Artic | Чёткость артикуляции, от размытой до выраженной. |
| Image | Стереоразведение голосов; 0% — по центру. Порядок позиций в полифонии взят из прошивки. |
| Detune | Расстройка голосов до **±40 центов**, работает и в полифонии, и в унисоне. |
| Release | Отпускание ноты: **1 мс…10 с**, экспоненциальная шкала JIANT. Конечные согласные успевают прозвучать и при коротком Release. |
| Voices | Общий лимит **1–8 голосов**; в Unison — количество слоёв одной ноты. |
| Master Volume | Общая выходная громкость **−60…+12 дБ**, по умолчанию **0 дБ**. Доступна для автоматизации. |
| Ext. Input Gain | Усиление внешней тональной несущей **−24…+24 дБ**, по умолчанию **0 дБ**. Нулевое положение уже включает +12 дБ относительно версии 0.3.0. |
| Mod Depth | Максимальное вибрато при полностью поднятом Mod Wheel: **0…±50 центов**, по умолчанию **±25 центов**. |
| Mod Rate | Скорость синусоидального LFO: **0,1…12 Гц**, по умолчанию **5 Гц**. |

Переключатель **Unison** собирает заданное число голосов на одной ноте.
В этом режиме новая нота заменяет прежний стек. Изменения количества слоёв
и режима применяются при следующем Note On; уменьшение лимита освобождает
лишние голоса. Detune, Image и настройки тембра действуют на звучащие голоса.

Галка **Mono** рядом с Unison оставляет одну текущую MIDI-ноту: следующая нота
заменяет предыдущую целиком, включая её хвост Release. Смена сглаживается
коротким переходом около 3 мс, без жёсткого обрыва волны. При включении Mono
уже наложившиеся старые ноты убираются. Вместе с Unison сохраняется один стек
из выбранного числа голосов. По умолчанию Mono выключен; доступна автоматизация.

**Newspeak** переключает чтение на одну фонему за MIDI-ноту: например,
«мама» → м → а → м → а. Работает во всех девяти языках и сохраняет
различие твёрдых и мягких согласных. Смена режима начинает строку заново;
сам текст остаётся прежним. Переключатель доступен для автоматизации.

Отдельные согласные можно вводить без гласной во всех языковых режимах:
`s`, `sh`, `m` удерживаются нотой; `g`, `k`, `p`, `t` дают короткую смычку
и взрыв, затем затихают. Дополнительная гласная не подставляется.
В RU `р` раскатистая, а `рь` — её мягкий вариант.

Все ручки, Ext. input, Pitch Bend Range, Unison и выбор строки доступны DAW как параметры автоматизации.
Перетаскивайте ручки вверх/вниз; также работают колесо мыши и клавиши-стрелки.
Двойной щелчок возвращает значение по умолчанию. Автоматизация читается на
временных отметках хоста и применяется к ближайшему внутреннему DSP-блоку.
CC120 / CC123 останавливают все голоса при поддержке VST3 MIDI mapping хостом.

## Ext. input и Pitch Bend

Включите **Ext. input** и подайте стереоаудио в aux-вход Sidechain плагина.
В Studio One включите сайдчейн в заголовке инструмента и направьте туда посыл
с нужной дорожки. Маршрутизация зависит от версии хоста.

Внешний сигнал заменяет **только тональную несущую**. Шипящие, аспирация,
дыхание, текст, артикуляция и огибающая остаются внутренними. MIDI-ноты по-прежнему
нужны для запуска слогов. Левый и правый каналы имеют собственные состояния
формантных фильтров. Без входного звука тональная часть молчит; шум согласных
может звучать. Detune и Pitch Bend не транспонируют внешний звук.
В версии 0.3.1 входной уровень внешней несущей поднят на **12 дБ**;
это новое нулевое положение ручки **Ext. Input Gain**. Её дополнительное усиление
и автоматизация не затрагивают внутренние шумы согласных.

Меню **Pitch bend** задаёт диапазон **±2…±12 полутонов**, по умолчанию ±2.
Колесо MIDI обрабатывается отдельно по каналам и изменяет высоту внутренней
несущей. Дефолт тембра: **Buzz 100%**, **Breath 5%**.

**Mod Wheel (MIDI CC1)** вводит синусоидальное вибрато внутренней несущей:
колесо внизу — без этого эффекта, вверху — полная глубина Mod Depth.
Положение ручки Mod Depth от колеса не меняется. Mod Depth и Mod Rate
сохраняются в проекте и доступны для автоматизации; колесо принимается отдельно
по MIDI-каналам и плавно изменяет интенсивность. LFO непрерывный, общий для
голосов одного экземпляра. В Ext. input внешний звук не транспонируется,
как и при использовании Pitch Bend.

## Языки и сохранение

ES, EN, JA (ромадзи), RU, DE, FR, ZH (пиньинь), PT, GN. Язык меняется с любым
введённым текстом: оригинал остаётся, а выбранные правила произношения применяются
к его транслитерации. Символы без фонетического соответствия сохраняются в тексте,
но при пении пропускаются. Правила новых языков приблизительные.
В RU «ы» имеет собственный профиль ближе к «и», а «е» и «э» различаются.
`ь` смягчает предыдущую согласную; перед е/и/ё/ю/я применяется контекстная
мягкость, `ъ` сохраняет разделение. Ч и Щ имеют мягкие русские профили.
Звонкие окончания остаются звонкими. При вводе латиницей мягкость можно
обозначать апострофом: `l'`, `r'`; разделение — двумя апострофами: `s''el`.
Таблица частот и устройство фонетики описаны в **PHONETICS.ru.md**;
настраиваемые значения — **src/RussianVowels.csv**.

Строки, язык, выбор строки и все ручки сохраняются в состоянии VST3 — вместе
с проектом DAW и в пресетах хоста. Старые проекты загружаются: первые 13 строк
видны в поле; прежние строки 14–16 сохраняются в данных для совместимости.

## Технические границы

Внутренний DSP всегда работает на **44 100 Гц** блоками по 64 сэмпла, как в FM-1.
Вход и выход приводятся к частоте проекта простой линейной интерполяцией;
при 44,1 кГц интерполяция обходится. Буфер сайдчейна добавляет около **1,5 мс**;
плагин сообщает задержку хосту для компенсации. Педаль sustain пока не добавлена.
Добавленная при переносе выходная сатурация удалена. Голоса суммируются
линейно, без автоматической нормализации в полифонии и унисоне: новые ноты
и хвосты Release не меняют уровень остальных голосов. Общий уровень задаётся
ручкой Master Volume. Защитные ограничения родного VOICE сохранены.
Длинное отдельное слово обрабатывается в рамках ограничения фонетического
читателя upstream: 19 латинских букв на токен. Происхождение кода и лицензии
описаны в UPSTREAM.md; публичная надпись preview в интерфейсе убрана.

В RU Л и Ль имеют усиленные профили; финальная Л получает около 80 мс
для артикуляции перед отпусканием. Ы немного опущена по формантам.
Я в начале слова даёт й-а, после мягкой согласной — отдельный профиль мягкой а;
после гласной или разделителя сохраняет йотацию.
