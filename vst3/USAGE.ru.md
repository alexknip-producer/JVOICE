# JVOICE 0.1.0 — первая тестовая сборка

VST3-инструмент для Windows x64. Движок VOICE из preview JIANT V10.7.16.

## Установка

Распакуйте папку `JiantVoice.vst3` в
`C:\Program Files\Common Files\VST3\` и обновите список плагинов в DAW.
Папку нужно перенести целиком, включая `Contents/x86_64-win/JiantVoice.vst3`.
Плагин определяется как инструмент **JIANT Voice**.

## Игра и текст

- 16 строк по 128 символов Unicode; русский текст вводится кириллицей.
- MIDI-ноты с номерами **0–15** выбирают строки **1–16** и не звучат.
  Номер надёжнее названия октавы: DAW обозначают октавы по-разному.
- Ноты **16–127** задают высоту. Velocity управляет уровнем.
- Новая нота продвигает текст на слог. Ноты аккорда с одной временной
  отметкой используют один слог. Удержание продолжает гласную; Note Off
  завершает ноту. Восемь голосов; девятая нота вытесняет самый старый.
- При выборе строки чтение начинается с её начала. Уже звучащие ноты
  продолжают прежний текст. Кнопка Restart line возвращает выбранную строку
  к началу. Пустая строка не начинает новые звуки.
- CC120 / CC123 останавливают все голоса, если хост передаёт VST3 MIDI mapping.
- В меню языка: ES, EN, JA (ромадзи), RU, DE, FR, ZH (пиньинь), PT, GN.
  Новые языки используют приблизительные фонетические правила preview.
- Выбранный язык общий для 16 строк. Кириллица принимается в RU. Для смены
  на другой язык сначала замените кириллицу латинским текстом.

## Где хранится текст

Исходные строки UTF-8, язык и выбранная строка сохраняются в состоянии VST3:
в проекте DAW и в пресетах, которые сохраняет хост. Внешний файл не нужен.
Автоматическая транслитерация готовится отдельно; исходная кириллица остаётся.
Таблица для дальнейшего редактирования: **src/TransliterationTable.h**.
После изменения таблицы нужна пересборка. Оригинал из JIANT указан в UPSTREAM.md.

## Ограничения этой версии

Это alpha для проверки в вашей DAW. Интерфейс простой, звук пока моно,
одинаковый в обоих стереоканалах. Педаль sustain и pitch bend ещё не добавлены.
Внутренний DSP работает на 44,1 кГц блоками 64 сэмпла; для другой частоты
хоста используется линейный ресэмплер. Задержка MIDI до одного внутреннего
блока (~1,45 мс) сверх буфера хоста. Sample-accurate автоматизация выбора
строки пока не реализована: автоматизация применяется на границе блока DAW.
Длинное отдельное слово всё ещё обрабатывается в рамках ограничения
фонетического читателя upstream (19 латинских букв на токен).

Перед распространением бинарника получателям должен быть доступен полный
соответствующий исходный код под GPL-3.0-only, включая изменения JVOICE.
